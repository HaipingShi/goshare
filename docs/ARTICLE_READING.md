# AI 文章目录与思维导图

Markdown、DOCX 文章正文页和首页渲染预览支持两种阅读结构：

- **AI 分析全文**：将文章文本块提交给现有 Workers AI binding，提炼全文摘要、主题及子节点。节点引用实际原文段落，点击可跳转，悬停可查看节点摘要。思维导图使用同一棵主题树。
- **标题目录**：根据原文 H1–H6 生成目录，作为初始导航及分析失败时的基础功能。AI 完成后可随时切回。

AI 目录支持搜索、折叠和阅读位置提示；导图支持缩放、重置、源码查看。没有标题的文章也可以分析。模型输出只作为文本和树结构使用，应用自行生成 Mermaid，模型不能返回可执行脚本或指定跳转 URL。

## 接口与配置

`POST /api/pages/article-analysis`

```json
{
  "blocks": [
    { "id": "block-1", "text": "学习从理解问题开始。" },
    { "id": "block-2", "text": "实践与复盘帮助形成可迁移的经验。" }
  ]
}
```

成功响应包含 `analysis.title`、`analysis.summary`、`analysis.nodes`、`analysis.nodeCount` 和 `quota`。每个节点包含 `title`、`summary`、`blockId`、`children`。客户端维护原文块与 DOM 元素的对应关系，节点无法跳到模型指定的任意页面。

复用 `AI_ENABLED`、`AI_BEAUTIFY_MODEL`、`DAILY_AI_LIMIT` 和 `AI` binding，无需新增生产 Secret 或数据库迁移。与智能美化共用访问者每日 AI 额度，模型调用失败也可能消耗一次额度。`AUTH_ENABLED=true` 时接口沿用站点登录校验；首页沙箱预览通过父页面发起请求，以保留登录 Cookie。

## 输入和结果限制

- 分析完整的文章文本、表格文字、图片替代说明及图表源码，不对输入静默截断；不分析图片像素。
- 单次最多 64K 字符、400 个非空原文块。超长文章须拆分后分析。
- 模型结果最多 60 个节点、4 层，所有节点必须引用请求中存在的原文块。格式错误或不存在的引用会返回 `502 AI_ANALYSIS_FAILED`。
- 验证能确保引用目标存在，不能保证 AI 对原文的理解完全正确，应结合原文核对摘要与分组。
- 阅读页即时分析的结果保留在内存中，切换模式不会再次计费。通过首页工作流生成的分析和图形随正文保存，刷新后可恢复，无需重新分析。
- 达到额度返回 `429 QUOTA_EXCEEDED`；AI 关闭返回 `403 AI_DISABLED`。失败不会删除原文或标题目录。

## 本地验证

单元测试使用模拟 AI 输出，覆盖全文输入、原文引用、格式限制、认证及额度。真实推理需要连接 Cloudflare 的 AI binding，可在 Git 忽略的本地配置中明确设置 `ai.remote=true` 和正确账号，保留 D1、R2 为本地资源。生产配置和 Secret 不应提交。
